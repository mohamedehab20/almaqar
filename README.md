# Al Maqr (المقر)

A digital HQ for companies: a live virtual office, department rooms, approval workflows, AI agents, a client portal and a learning academy. Arabic-first (RTL) with English support. Built with Next.js 16, React 19, Tailwind CSS v4 and next-intl.

```bash
npm install
npm run dev   # http://localhost:3000
```

**Developer reference:** start with [development-almaqar/README.md](development-almaqar/README.md) — setup, architecture, routes, milestones, decisions and the backend handoff list.
